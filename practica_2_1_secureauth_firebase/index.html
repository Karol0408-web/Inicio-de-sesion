SecureAuth

Módulo de inicio de sesión seguro con Firebase Authentication.

  • ✓ Validación de correo y dominio
  • ✓ Política de contraseña segura
  • ✓ Contraseñas gestionadas por Firebase Auth
  • ✓ Verificación de correo
  • ✓ MFA mediante SMS

Bienvenido

Correo → contraseña → segundo factor → acceso.

Crear cuenta

La contraseña nunca se almacena en texto plano por esta aplicación.

✗ Mínimo 8 caracteres
✗ Una mayúscula
✗ Una minúscula
✗ Un número
✗ Un carácter especial
